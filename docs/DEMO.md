# Трёхминутный показ жюри

**0:00–0:25 — проблема.** «У жителя течёт потолок или не работает лифт. Он не знает, куда писать. Ошибка адресата затягивает решение».

**0:25–1:15 — путь жителя.** Откройте `http://127.0.0.1:8000`. Введите «В подъезде не горит свет», выберите дом и место. Покажите карточку ЕДЦ: куда обращаться, что приложить, что делать сейчас. Прикрепите тестовое фото и создайте заявку.

**1:15–1:50 — операционный контур.** Во вкладке «Диспетчеру» введите ключ `hackathon-demo`, смените статус. Вернитесь во вкладку жителя и покажите обновившуюся шкалу. В реальном пилоте статус пришёл бы из системы исполнителя.

**1:50–2:25 — MAX.** Во вкладке «Бот MAX» отправьте `/start`, затем `1`, «Во дворе не убран снег», `3`, `нет`, `2`, `да`. Покажите номер заявки и маршрут на «Наш город». Симулятор работает без внешнего токена, а настоящий webhook и отправка через официальный API уже описаны в коде.

**2:25–3:00 — честный результат.** 6 000 синтетических московских формулировок, ML для темы, правила безопасности и маршрута. `macro-F1 0,9372` — только синтетический тест. Пилотные метрики на реальных заявках: время до правильной заявки, доля без переадресации, завершение сценария и повторы.

Запасной аварийный кейс: «В лифте застрял человек» — бот должен сразу показать `112` и диспетчерскую. Кейс неопределённости: «Во дворе не убран снег» без ответа о принадлежности территории — заявка блокируется до уточнения.
