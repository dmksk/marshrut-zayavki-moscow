# Показ мини-приложения MAX за 3 минуты

## Перед выступлением

1. Поднимите сервер на публичном HTTPS-адресе с `APP_PUBLIC=1`, `MAX_BOT_TOKEN` и длинным `APP_ADMIN_KEY`.
2. В [настройках бота MAX](https://dev.max.ru/docs/webapps/introduction) привяжите адрес `https://ваш-домен/mini` и выберите кнопку «Открыть». Для создания бота нужен верифицированный профиль организации, ИП или самозанятого.
3. Проверьте на телефоне, что мини-приложение открывается из чата, создаёт заявку и показывает её в «Мои заявки».
4. Держите открытым локальный кабинет `/admin` с ключом диспетчера.

## Сценарий

**0:00–0:20 — проблема.** «В подъезде не горит свет. Житель не знает, кому писать».

**0:20–1:15 — мини-приложение.** Откройте чат с ботом MAX и нажмите «Открыть». Выберите демо-дом, введите «В подъезде не горит свет», укажите «подъезд» и «нет» на вопрос об опасности. Нажмите «Определить маршрут». Покажите карточку: первый канал, действия сейчас, материалы и ожидание ответа.

**1:15–1:55 — заявка.** По желанию добавьте тестовое фото. Нажмите «Создать демо-заявку», затем откройте «Мои заявки». Подписанные данные MAX связывают заявку с открывшим приложение пользователем.

**1:55–2:35 — статус.** В кабинете диспетчера `/admin` введите `APP_ADMIN_KEY` и переведите заявку в «назначен исполнитель». Житель видит статус в мини-приложении и получает сообщение бота в MAX. Повторите для «выполнено».

**2:35–3:00 — результат.** ML предлагает одну из шести тем; правила обрабатывают срочные случаи и маршрутизацию. Демо использует 6 000 синтетических московских формулировок. `macro-F1 0,9372` относится только к синтетическому тесту. Заявка не отправляется в реальные городские системы.

Дополнительный кейс: «В лифте застрял человек» показывает срочные действия и `112`. Для двора сначала уточняется принадлежность территории.

## Если бота и HTTPS-адреса пока нет

Запустите `make run`. Откройте `http://127.0.0.1:8000/mini`: можно пройти вопросы, создать локальную тестовую заявку и увидеть её статус. Кабинет диспетчера доступен по адресу `http://127.0.0.1:8000/admin`; локальный ключ — `hackathon-demo`. Этот режим работает только при локальном запуске без токена и не выдаёт себя за авторизацию MAX. На выступлении называйте такой показ предпросмотром, а не работающим мини-приложением внутри MAX.

`make max-demo` запускает запасной текстовый диалог в MAX через Long Polling при наличии токена. Этот режим не заменяет публичный HTTPS-адрес для мини-приложения.
